# PortfolioDashboard

![angular](https://img.shields.io/badge/angular_v21-darkred?style=for-the-badge&logo=angular)
![tailwindcss](https://img.shields.io/badge/tailwindcss_v4-black?style=for-the-badge&logo=tailwindcss)

A read-only portfolio and résumé dashboard for my software engineering work.
Built with Angular 21, Tailwind CSS v4, and a C# / .NET REST API.

Features
---

- Overview - Counts and context for projects, skills, and experience.
- Timeline - Roles, responsibilities, projects, and technology chips.
- Profile - Bio, GitHub/CV links, recommendations, and skills.
- Blog - Notion-backed posts with links to the public pages.

Loading, empty, and error states are handled on every data screen. The app ships
with light and dark themes.
